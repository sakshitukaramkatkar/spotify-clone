# 🎵 Spotify Clone

A simple Spotify-inspired music player interface created using **HTML and CSS**.

## 📌 About the Project

This project is a front-end clone inspired by the Spotify music streaming interface.  
It focuses on recreating the layout, navigation, music cards, sidebar, and music player section using HTML and CSS.

## ✨ Features

- 🎵 Spotify-inspired user interface
- 🏠 Home and navigation section
- 📚 Library section
- 🎶 Music/album cards
- ▶️ Music player interface



## 🛠️ Technologies Used

- HTML5
- CSS3
